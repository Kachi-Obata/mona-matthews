# Mona Matthews — Nigeria's Finest Shoe Designer

A luxury footwear brand website for **Mona Matthews**, proudly crafted in Nigeria since 2002. Specialising in handmade shoes with elegant, extended sizing for men and women.

🔗 **Live site:** [monamatthews.com](https://monamatthews.com)

---

## ✨ Features

- **Curated Collection** — Six signature shoe designs with high-quality product photography
- **Interactive Size Guide** — Toggle between men's and women's sizing (UK, EU, US, JP) with animated transitions
- **Inclusive Sizing Focus** — Beautifully proportioned footwear designed especially for larger sizes
- **Responsive Design** — Optimised for desktop, tablet, and mobile
- **Scroll Animations** — Subtle fade-in effects on each section using Intersection Observer

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure |
| Vanilla CSS | Styling with CSS custom properties |
| Vanilla JavaScript | Interactive size guide & scroll animations |
| Google Fonts | Playfair Display (headings), Inter (body) |

No frameworks. No build tools. Just clean, hand-crafted code — much like the shoes.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Kachi-Obata/mona-matthews.git
   cd mona-matthews
   ```

2. **Open in a browser**
   ```bash
   open index.html
   ```
   Or use the **Live Server** extension in VS Code for auto-refresh on save.
